# Roast Your Own Operator in One Line

This Python 3 program writes a one-line roast to `entry.txt` in the directory set by `MAKEFUN_OUTPUT_DIR`, which defaults to `/output`.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
